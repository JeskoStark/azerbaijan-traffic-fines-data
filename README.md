# Road fines data pipeline

Учебный проект: CSV → Python ETL → PostgreSQL в Docker. Источник: открытый справочник дорожных штрафов surucu.az. В текущем файле 69 строк и 11 столбцов; это правила и размеры санкций, а не записи о реальных случаях нарушения.

## Что происходит

1. `data/fines.csv` — исходный файл. Сохраняем оригинал, чтобы загрузку можно было повторить.
2. Python читает CSV, проверяет наличие ожидаемых полей и преобразует суммы/баллы в числовые типы.
3. PostgreSQL хранит подготовленные записи в таблице `road_fines`.
4. SQL-запросы в `sql/analysis.sql` помогают исследовать суммы, баллы и пропуски.
5. Docker Compose запускает PostgreSQL и Python-загрузчик в согласованной среде.

## Запуск

Нужны Docker Desktop и Docker Compose.

1. Создайте файл настроек из шаблона: `Copy-Item .env.example .env` (PowerShell) или `cp .env.example .env` (macOS/Linux).
2. Запустите `docker compose up --build`.
3. В логе загрузчика должно появиться `Loaded 69 rows ...`.
4. Выполните запросы: `docker compose exec db psql -U student -d fines -f /sql/analysis.sql`.
5. Остановите контейнеры: `docker compose down`. Данные PostgreSQL останутся в Docker volume. Чтобы удалить базу и начать с нуля: `docker compose down -v`.

## Пошаговое объяснение

### 1. Источник и схема

CSV содержит азербайджанские заголовки: `ixm_maddesi` — статья, `pozuntu` — нарушение, `tesvir` — описание, `cerime_min_azn` и `cerime_max_azn` — диапазон штрафа, `cerime_bali` — баллы. Код сопоставляет их с понятными именами столбцов PostgreSQL.

### 2. Извлечение и проверка (Extract)

`csv.DictReader` читает строки по именам колонок. Код проверяет заголовки и останавливается с понятной ошибкой, если структура файла отличается. Кодировка `utf-8-sig` также читает CSV с BOM.

### 3. Преобразование (Transform)

Пустые значения для штрафов и баллов переводятся в SQL `NULL`; суммы преобразуются в `NUMERIC`, баллы — в `INTEGER`. Сохраняются и исходные азербайджанские текстовые значения.

### 4. Загрузка (Load)

Скрипт создаёт таблицу, очищает её перед повторной загрузкой и вставляет строки. Для этого справочного датасета такой повторный запуск формирует актуальную копию файла, избегая дубликатов по статье.

### 5. Анализ

Запросы в `sql/analysis.sql` дают число статей, показывают наибольшие минимальные штрафы, распределение баллов и незаполненные пределы штрафов. Дата `son_yenilenme` относится к обновлению источника, поэтому по ней нельзя анализировать фактическую частоту нарушений.

## Обновление CSV

Замените `data/fines.csv` новой версией с теми же заголовками, затем повторите `docker compose up --build`. Загрузчик полностью заменит строки таблицы новыми данными.
